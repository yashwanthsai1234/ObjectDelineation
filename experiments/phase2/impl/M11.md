## Design choices and evidence

- **Bootstrap = B2's draws, not a count matrix.** Options: loop over index draws (B2-identical) vs one
  bincount-matrix product. 128 items: 2.4 ms vs 2.9 ms per metric, max |diff| 3.5e-17. Kept the loop: identical to
  B2 to the digit and not slower. Whole panel on 128 items: 0.06 s; `spearman_ci` on 128 items: 0.21 s.
- **Reproduces B2 on every scored run** (scratch `phase2/impl/G/evidence.py`): 320 of 320 table CIs of
  `analysis.json` + `posthoc.json` (10 runs x 2 views) and 30 of 30 paired posthoc CIs equal at B2's 4-dp rounding.
- **R-B on B2's depth pairs (all forced eligible, shifted):** LFM keeps 150 steps under sd_geom (Δ −0.005), r_std
  would veto (+17 %, CI > 0) → `disagree` True: the legality-part effect D12 names. SmolVLM, Qwen3.5: deep, no flag.
- **R-B walk:** "pairwise downward" read as: compare the current pick with the next shallower eligible branch, move
  if the veto fires, stop at the first pair that does not. The r_std walk runs on the same memoised pairs.
- **Veto margin** relative to the deeper branch's mean on the aligned items (B2 prereg wording); deeper value 0 and
  shallower > 0 counts as ≥ 15 %. "No significant IoU loss" = paired (shallow − deep) median IoU_tc CI upper ≥ 0.
- **c2 stratified bootstrap** copies `power_c2.pooled` (same rng call order) so it equals it to 1e-15 (test).
- **Fourth-seed clause:** eligible iff 3 seeds, none < 0.30, 1 or 2 of 3 ≥ 0.50 (one seed crossing 0.50 flips
  clause (2)), and flipping clause (2) changes the outcome; owner approval stays with the caller.
- **C2 outcome:** fail first (pooled < 0.30 → R-ctrl), then pass (all clauses → none), else partial (R-x8 unless
  clause (4) failed). Exhaustive table test: 6 pooled levels x 2^5 clause combinations → exactly one outcome, ≤ 1
  conditional, and all four (outcome, conditional) pairs reachable.
