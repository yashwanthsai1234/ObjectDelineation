## Design choices with evidence

| choice | options tried | evidence | picked |
|---|---|---|---|
| NSD surface | (A) DeepMind surfels: corner grid of 2×2 codes, weighted by contour length; (B) 4-connected boundary pixels, unit weight (A4 S2) | 897 real val rater pairs (every 10th LIDC, 4th RIGA item): \|A − B\| median / p95 / max = 0.008 / 0.065 / 0.139 nodule, 0.001 / 0.017 / 0.037 disc, 0.001 / 0.017 / 0.031 cup; time 3.8 vs 4.2 ms per pair. Only (A) can equal the DeepMind reference; LIDC median NSD@2 = 0.969 (A4 S2: 0.97) | (A) |
| NSD multi-rater | max over raters (like D_max); vs vote | max gives 1 on a rater's own target (plan test); vote does not | max |
| NSD exactness | (l·[d ≤ τ]).sum / total vs 1 − (l·[d > τ]).sum / total | the first gives 0.9999999 for a = b; the second is exactly 1 and within 1e-15 of the reference | second |
| HM-IoU, k ∤ K (LIDC k = 3 at K = 8 / 16) | (a) raters tiled ⌈K/k⌉ times, rectangular LSA; (c) balanced: every rater matched ⌊K/k⌋ or ⌈K/k⌉ times (mandatory copies forced by a bonus) | random 8×3, 16×3, 7×3, 5×2 matrices (8,000): (a) leaves a rater below ⌊K/k⌋ in 29 % of cases and scores up to 0.104 higher; both equal the published square matching when k \| K (test) | (c) |
| eval_run prepared path | build caches from store frames vs prepared caches | 38 real val items: 1.2 s vs 2.9 s (2.5×), identical JSON | prepared, loaded in the worker (`caches=` loader or per-process `cache_loader`) |
| single-rater items | score vs skip | the reward needs ≥ 2 raters (τ from rater pairs); prepared val has 0 such items, the store's synthetic fixture 1 | skip + count in `report["skipped"]` |
| G-vision fixture | Llava tiny (CLIP + 2-layer projector + Llama) vs SmolVLM / Qwen tiny | Llava's processor builds offline from a WordLevel tokenizer + `CLIPImageProcessor`; ~0.3 s per model | Llava |

## API as built

- `metrics(..., tokens=None, nsd_tau=NSD_TAU)`: per object `"nsd"` (per sample), `"hm_iou"`; per sample
  `"truncated"`, `"tokens"` (when given). `hm_iou(iou (K, k))`, `nsd(a, b, tau)`, `NSD_TAU = {nodule 2, disc 9, cup 16}`.
  `summarize`: `"truncated"`, `"tokens": {"mean", "p95"} | None`, per object `"hm_iou"`, `"nsd_mean"`, `"nsd_median"`.
- `vision.check(model, processor, images, items, *, reference, prompt=None, T=24)` → `{"ratio", "distance",
  "reference", "tv" (min), "tv_black", "tv_other", "pass_ratio", "pass_tv", "pass", "action"}`;
  `projector_distance(base, processor, images)` gives `reference` (R0); `decide(ratio, tv_black, tv_other)` is the
  rule (abort both / warn one / ok); `fixed_set(prepared_root, n=8)` → (items, SHA-256) = B1's sets (verified equal
  to `lab/B1/common.eval_records("lidc", 64)[:8]`); pinned hash `b776dd12…` on `data/prepared`.
- `gates.phase2_entry(report, datasets=None)`: schema in the module docstring; gate keys = `prereg.C1_GATES`
  (`G-format`, `G-geometry`, `G-prior-b`, `G-precision`, `G-topology-a`, `G-signal`, `G-vision`); `"passed"`
  {gate: bool} incl. `G-probe` is `prereg.c1_stop`'s input; `"reported"` holds `G-prior-a`, `G-topology-b`, `G-probe`,
  truncation and tokens; `"warnings"`. `topo_any_unanimous` is no longer read (still reported by summarize).
- `eval_run`: `load_prepared(root, split, ids)`, `skipped(rows, frames)`, `evaluate(rows, frames, procs, caches=None)`,
  `build_report(results, baseline, datasets, view="shifted", skipped=None)`; CLI `--prepared`, `--view`; rows may carry
  `"tokens"`.
