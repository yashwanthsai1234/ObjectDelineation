- TRL documents `rollout_func` (prompts, trainer -> dict of lists) but under trl.experimental.openenv; no source states it is stable. ## Recommendations

Decision (ADR-style): adopt 7 packages under src/objdel with an acyclic order geom < verify < data < policy < {rl, sft} < infra; experiments keeps only thin CLIs and frozen research. Trade-off: one big move commit (many import edits, tests renamed) vs permanent two-home confusion. Consequence: tests/ import only objdel.*; experiments never imported by tests, nothing imports experiments.

Allowed imports (enforce with import-linter, `contracts: layers` in pyproject; ruff TID251 banned-api for `experiments`/`tests` inside src):
geom: none | verify: geom | data: geom, verify | policy: geom, verify, data | rl: policy, data, verify, geom | sft: policy, data, verify, geom | infra: any lower layer except rl/sft internals (talks to them only by argv/module name).
