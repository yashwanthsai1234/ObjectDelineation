
- **ADR-0014 Scheduled RL rows.** Options: (a) reweight the 3 fixed windows; (b) online draws with GPU-derived
  tables (SD3); (c) offline multi-draw pool, schedule, materialize only scheduled rows. (a) fails the coverage gate
  [measured: SD3 s5]. (b) needs new GPU table and render parity first (Phase D work). Decision: (c). It meets the
  cell shares by construction, needs no new GPU code, and keeps disk use flat. Revisit when Phase D gives
  parity-checked GPU tables; then (b) removes materialization.
  - **Target law.** Options: val-shape cell shares (40 patients), the train shifted law (7,341 items, 557
    patients), or a pooled law. Decision: the train shifted law. Its distance to val-select is TV 0.063, offset KS
    0.037; val-shape's is TV 0.169, KS 0.099 [measured: docs/implementation2.0/notes/b_final/trainlaw.json]. The offset
    law is the generator's (`augment.shift`, uniform over the admissible rectangle [code:
    src/objdel/targets/augment.py:58-71]), so a patient sample adds only a noisy size mix. The train law also uses
    no val data. It equals the test view's generator law **by choice**; the `edge`-law, rescaled and rotated val
    views guard against fitting that one law (B1.6, Gate B1).
  - **Size axis.** The cell size is the apparent size `extent_px x S0 / side` for every kind (equal to
    `extent_px` for centred and shifted windows). A rescaled window with a larger side shows the object smaller, so
    raw `extent_px` would put it in the wrong cell.
  - **Confound.** B1 continues `rl-full-3ep` for 300 more steps; R5 is that start model. Part of a gain can be
    extra training. Evidence that more centred steps add about 0: the held-out IoU plateau over the last epochs of
    the 770-step run [measured: docs/research/notes/rl_plateau_diagnosis_2026-11-08.md]. Within-run check: the
    per-cell logs (offset < 0.15 cells flat, off-centre cells rising). Gate B1 reports the near-centre gain as the
    control (B.6.2).
  - **Exception:** B1.4 targets use the numpy polygonizer until Phase D K1 passes parity (owner sign-off, B.8.3).
- **ADR-0012 Number match.** Options: A fp16 in both + token TIS (C = 2); B bf16 + token TIS (C = 2); C keep
  `sequence_mask` (the control; drops long answers); D bf16 + token TIS + geometric sequence mask [0.99, 1.01]

- **ADR-0013 Reward v5.** Mean-centred group baseline written as RLOO (equal to mean-centring times 8/7 for G = 8),
